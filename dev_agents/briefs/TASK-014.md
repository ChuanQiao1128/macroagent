# Agent Brief: TASK-014 Vision Structured Uncertainty Schema

## Goal

Upgrade the Claude Vision output from a single food name per component into a
structured uncertainty schema with top-k food candidates, visual evidence,
portion confidence, state, and hidden ingredient risks.

## User Value

MacroAgent should use the LLM as a perception and uncertainty engine, not as a
calorie calculator. This task lets Claude express what it sees, what it is unsure
about, and which alternatives are plausible.

## Acceptance

- Extend the vision response schema while preserving compatibility with existing
  `FoodComponent` consumers.
- Add structured models for:
  - image quality / usability issues
  - component id
  - top-k food candidates with confidence and visual evidence
  - visible name
  - portion description, confidence, and visual basis
  - state hints such as cooked/raw/fried/grilled/plain/sauced where visible
  - hidden ingredient risks with likelihood and macro impact
  - meal-level uncertainty flags
- Keep Claude output constrained through tool schema / structured output.
- The default analyzer should still return a list usable by existing meal
  analysis code, but expose a new API for the full structured response.
- Do not ask Claude for kcal, protein, carbs, fat, or final meal totals.
- Add tests for parsing:
  - full structured response
  - legacy/simple component response
  - retry on invalid structured payload
  - hidden ingredient risk fields
  - no nutrition-number fields generated by the schema
